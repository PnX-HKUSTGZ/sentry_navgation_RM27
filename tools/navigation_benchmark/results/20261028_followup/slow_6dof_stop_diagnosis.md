# 6DoF slow seed 42 停车诊断

[原始超时段](full_chain_slow_seed42/repeat_01/run_02.json) 与 [启动日志](full_chain_slow_seed42/repeat_01/launch.log) 保留全部失败数据。首段成功，耗时 30.30 s，主口径候选 0；第二段 89.94 s 超时，主口径 1 个候选、1 个长停，持续 77.82 s（仿真时间 50.642–128.462 s）。真值停点约 (7.558, 7.408, 0.325) m，距目标约 11.14 m；没有后续路段可计为成功或零停车。

候选期间观察到的 1298 个样本，其 `/cmd_vel` 时间距采样均≤0.2 s，水平速度命令全部为零；因此这里没有持续非零命令推动车体的证据。该时段记录 62 条轨迹安全拒绝、60 条逃逸轨迹拒绝、74 条控制器 `BLOCKED`、2 条 `BLOCK_COMMAND`；示例中 `PRIOR_MAP` 车身重叠 0.3474 超过 0.04，且重叠深度超出 0.03 m 门限。保护触发明确，不等于已证明真实碰撞或误停。

同一时段有 38 条 `camera_init`→`map` 水平姿态超限而关闭地面支撑的日志；停留样本的最新定位 TF 与真值平移差中位数约 (-0.009, -0.471, -0.001) m。TF 不是与真值严格同一时刻的同步样本，尽管真值几乎静止，仍不能将此数值当作标定定位误差。长停前局部 GICP 曾因 z 修正超出门限拒绝；不能凭这些并存信号证明唯一因果链，也不能放宽保护门限。

使用记录的真值完整姿态与仿真车轮球半径 0.08 m、车轮中心偏移 (±0.218, ±0.218, 0)，将开始、中间、末尾三个姿态的轮球心与实际场景 barrier 三角面逐个求最近三维距离（计算方法同 [gravity_contact_audit.py](../../gravity_contact_audit.py)）：最近均为 `barrier_0086`，分别约 0.13049、0.13043、0.13043 m；轮球到网格面名义间隙约 0.0504 m。此计算仅覆盖四个轮球、三个离散时刻和静态障碍三角面，不覆盖车体其他部位、实际接触力、全部扫掠或不确定度，不能作为整车无碰撞或保护误判的证明。

与 `full_chain_transport_seed42` 比较，保存的参数快照仅近障碍速度 0.8→0.6 m/s；但两次 manifest 的 `relocalization_manager` 二进制哈希及 git diff 哈希不同。两者各只有一次，故不能把结果差异归因于速度修改，也不能据一次改善将 0.6 m/s 当作完整链的可靠解决方案。
