# PGM 权重改动复核（2026-10-31）

结论：权重确实影响运动，但上一轮实现有可复现的逻辑漏洞，原有单元测试不足以证明没有 bug。本次已修复下列问题并完成构建、311 个 GTest 回归。完整导航仍有失败场景，不能认定已满足“快速过洞且动态避障完全正常”。

## 已确认并修复

1. **薄障碍片互相充当地面证据，导致误放行。** 一片尚未与地面独立连通的离地薄回波，在权重 0.5／1 下可凭相邻同高度回波得到通行判定。原来的硬阻挡只检查孤立单格，并把未经验证的邻居高度当作地面。现在车体高度区间内的这类回波使用独立连通地面或车体参考平面复核，不能用自身回波群构造地面高度。新增浮空障碍片复现及真实斜面反例测试。
2. **权重 0 仍借用白区证据。** 原有屋顶复核允许 PGM 白区使用单侧地面拟合，随后把它记为完整地面证明；即使新权重为 0 也会放行。现在权重 0 禁止这条先验辅助分支；单侧先验辅助结果只计作部分证据，不能冒充完整实测证明。
3. **新评分覆盖了原有地面连通保持。** 分数在保持判定前计算，导致仍在有效保持期内的实测地面被重新判为阻塞。现在保持结果进入最终证据判断；不延长原保持截止时间，变化的地面和新障碍仍阻挡。
4. **在线参数修改的假成功。** 之前 ROS 参数可能接受新权重，内部配置却不更新。现在声明为只读启动参数，并在 MINCO 配置阶段参数保护中补上它；运行时修改明确拒绝，需修改启动配置后重启导航。
5. **配置组合没有约束。** 旧的 `require_ground_support=true` 会引入独立的先验地面放行途径，关闭净空检查又会使新权重逻辑不启用。现在加启动／底层配置校验：权重模式要求 `clearance_check_enable=true`、`require_ground_support=false`。当前实车和仿真配置均符合。
6. **仿真车高配置错误。** 仿真 `vehicle_height` 原为 0.040 m，而 `simulation_waking_robot.xacro` 的 `folded_vehicle_height` 为 0.240 m。该差异会放宽真实车体高度区间内的障碍判断。本次校正仿真为 0.240 m，并增加模型与配置一致性检查。实车尺寸保持其独立配置。

前三项均先新增失败用例，在修复前复现，再验证修复后通过。修复前输出见 `docs/validation/prior_weight_audit_regressions_before.txt`。

复核时工作区中的仿真权重已经为 **1.0**，实车为 **0.5**；保留了这两个值，没有把仿真改回 0.5。实际配置加载测试改为核对各文件所配置的数值，允许两套环境独立调参。

## 校正车高后的仿真

全部使用 0.240 m 车高。速度来自 Gazebo 真值里程计，按仿真时间计算并包含起停；1 倍仿真设置未改变。0.5／1.0 的对照均使用明确固定权重的配置副本。

| 场景 | 权重 | 结果 |
| --- | --- | --- |
| 三段平地、云台收起 | 0.5 | 2/3 到达，首段超时；平均 0.255 m/s |
| 三段平地、云台收起 | 1.0 | 3/3 到达，平均 1.208 m/s，无 ≥0.4 秒停顿 |
| 三段平地、云台持续转动 | 1.0 | 3/3 到达，平均 1.204 m/s，无 ≥0.4 秒停顿 |
| 北侧两目标 | 1.0 | 首目标到达；回程超时，出现 40.2 秒停滞 |
| 路径上新增 0.4×0.4×0.8 m 箱体 | 1.0 | 超时，真值足迹与箱体发生重叠并停滞，未成功绕行 |

**北侧失败未解决。** 主要拒绝样本位于约 `(8.03, 6.59)` 的机器人姿态附近，足迹检查点约 `(7.77, 6.86)`；日志显示 `prior_occupied=1`、`prior_free=0`、有效权重 0、证据约 `(0.5,1.0,0.5)`、`hard_obstacle=0`，拒绝原因为 `GROUND_UNVERIFIED`。这表明当时是非白区的地面证据门槛在阻挡，并非已确认实体障碍。需要继续核对静态足迹边界、局部投影和重叠脱困之间的交互；不能用平地到达结果证明过洞问题已完整修复。

**完整障碍感知／绕行未通过。** 新增箱体测试中，真值足迹重叠最大约 0.0284 m，导航超时。另做静止点云探测：箱体区域在原始雷达 `left_mid360` 和注册点云 `camera_init` 中均得到 0 个点。这个采样提示需要继续追查 Gazebo／点云输入链路，但尚不能仅凭单次探测断言整个运动期间都没有回波。本次没有宣称该感知问题已修复。

以上两项是复核暴露的未完成事项。权重 1 能消除部分证据不足造成的平地慢行，但不能替代感知系统观测障碍，也没有消除所有边界阻塞。实车尚未测试。
