# 北侧洞口短停修复（2026-10-10）

## 日志原因

检查的用户运行日志：
`~/.ros/log/planner_server_mt_3376439_1791611107190.log`。

北侧通道的车身中心约在 `y=7.54`，下侧轮廓采样点约在 `y=7.25`。
ROG 将边缘格判为 `GROUND_UNVERIFIED` 或 `HEADROOM_BLOCKED`，局部轨迹
因此触发 `COSTMAP_LETHAL`、`FOOTPRINT_COLLISION`，随后重规划、刹停或
`BLOCK_COMMAND`。这是本次短停在日志中可确认的触发链。

这些采样的 ESDF 距离曾为 -0.009、-0.013、-0.024 米。复测也发现同类致命格
对应的插值距离为 +0.005、+0.009 米：投影占据判定与连续 ESDF 插值不能简单
视为同一种几何判定。上述数值不是测得的实体车身碰撞深度。

## 修改范围

新增参数：`planner_server.ros__parameters.MincoPlanner.safety.dynamic_edge_overlap_tolerance`。

- 仿真 `config/simulation/minco_params.yaml`：`0.03` 米。
- 实车 `config/reality/minco_params.yaml`：`0.0`，关闭该容差。
- 只作用于已配置多边形、硬净空距离为零时的完整车身采样检查。
- 只接受低净空或地面验证类的动态致命格，且 ESDF 距离绝对值不超过容差。
- 采样点必须处于车身边缘带内，宽度为容差与半格分辨率的较大者。
- 原始 PGM 多边形检查仍先执行；原有静态面积和深度阈值保持不变。
- 墙体、模糊实测障碍、悬空地面未验证、车身内部障碍、过深距离、查询失败
  和过期地图不能利用该容差通过。未知格仍使用独立的 `allow_unknown_motion` 策略。

这是对仿真边缘离散误差的有限放宽，不是新的三维接触检测，也不能证明实车有
3 cm 的实体碰撞余量。因此没有给实车启用。

生效时日志包含 `Accepted shallow dynamic boundary cell`，启动日志显示容差值。
重新启动导航节点才能加载此参数和新代码。

## 最终验证

`minco_planner` 已编译安装，11 个 CTest 测试目标全部通过。新增回归覆盖默认
严格判定、正负近零距离、深重叠、内部障碍、墙体证据、静态障碍、未知格、
查询失败、过期地图以及非零硬净空距离。
